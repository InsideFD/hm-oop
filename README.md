# Интернет-магазина с классами: товары и категории.

## Реализованный функционал

### Класс Product
- Название товара
- Описание товара
- Цена
- Количество в наличии

### Класс Category
- Название категории
- Описание категории
- Список товаров в категории

### Дополнительные задание
- Загрузка данных из JSON-файла
- Полное покрытие тестами
- Соответствие PEP 8

## Установка и запуск

1. Установите зависимости:
```bash
poetry install
```
2. Запустите тесты:
```bash
poetry run pytest
```
3. Запустите основное приложение:
```bash
poetry run python main.py
