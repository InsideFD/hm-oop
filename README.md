# Интернет-магазина с классами: товары и категории.

## Реализованный функционал

### Класс Product
- Название товара
- Описание товара
- Цена
- Количество в наличии

### Класс Category
- Название категории
- Описание категории
- Список товаров в категории

### Дополнительные задание
- Загрузка данных из JSON-файла
- Полное покрытие тестами
- Соответствие PEP 8

### Наследование
- Классы `Smartphone` и `LawnGrass` наследуются от `Product`
- `Smartphone` расширен атрибутами: efficiency, model, memory, color
- `LawnGrass` расширен атрибутами: country, germination_period, color
- Ограничение сложения: можно складывать только товары одного класса
- Ограничение добавления: в категорию можно добавлять только продукты

## Установка и запуск

1. Установите зависимости:
```bash
poetry install
```
2. Запустите тесты:
```bash
poetry run pytest
```
3. Запустите основное приложение:
```bash
poetry run python main.py
```
